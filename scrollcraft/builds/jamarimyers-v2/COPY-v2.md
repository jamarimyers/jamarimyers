## How to read this file

Notation, none of which ships:
- `*word*` is the italic accent word in `--accent-2`. Headings end on it.
- `[LABEL: ...]` is a micro label (.6875rem uppercase).
- `FIGURE: 48 / caption` is a serif figure with tabular numerals and its caption.
- `[BUTTON: label -> href]` is a link or button. Mailto subjects are URL-encoded in the href.
- `[ALT: ...]` is image alt text. `[ALT: ""]` means decorative (the link label already names it).
- `[CONFIRM: reason]` is a question for Jamari. Strip it before build, keep the sentence only once he answers.
- `[GATE]` is a plan publish gate. The fallback ships until he confirms in writing.
- Provenance follows each block in braces, and is stripped before build:
  - `{owner: source}` is Jamari's own words, verbatim.
  - `{owner-adapted: source; change}` is his words with a stated edit (tense, person, a ban removed).
  - `{partner: source}` is a brand partner's words, verbatim apart from punctuation noted.
  - `{approved: CONTENT.md Lnn}` is the approved outward-facing Osmo wording, verbatim.
  - `{plan Lnn}` is a line the plan fixes.
  - `{v1: COPY.md Lnn}` is a line reused from the v1 copy panel.
  - `{draft}` is written by the brand editor (AI). It needs his read before it ships.
- Source shorthand: `CONTENT.md` = scrollcraft/builds/jamarimyers/CONTENT.md; `POSITIONING.md` = research/POSITIONING.md; `COPY.md` = scrollcraft/builds/jamarimyers/COPY.md; `old-site` = the original jamarimyers.com index.html in the scratchpad package; `plan` = the approved plan; `JAMARI.md` = research/JAMARI.md.
